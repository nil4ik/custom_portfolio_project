# Personal Portfolio & Collection Dashboard

This project is an interactive dashboard for managing and tracking personal collections, investments, or any valuable items in one place.  
It allows users to visualize how the total value of their collection changes over time, view item-level details, analyze their portfolio structure and many others usefull features.

The goal is to provide a flexible, visual “personal ledger” where users can:
- Record and update items they own.
- See the total portfolio value evolve over time.
- View charts showing growth trends and category distributions.
- Customize item parameters (e.g., price, date, condition, weight, etc.) depending on the collection type.

Future versions will allow users to add, edit, or remove items directly from the dashboard, and even define their own custom fields for each category.
